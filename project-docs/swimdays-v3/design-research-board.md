## Swimdays Direction Decisions

- Typography: editorial serif for display + clean sans body
- Color hierarchy: warm neutral base + restrained accent for actions
- Spacing system: large rhythm blocks, minimal clutter
- Motion policy: 3 interaction classes only
  - hero scroll cue
  - image hover reveal
  - subtle button lift
- Product storytelling order on PDP
  - price and title
  - embroidery/value indicators
  - size/variant controls
  - care instructions
